Quick setup

  1. Open iverson.io and tap Link. Note the 4-digit code.
  2. On your Mac, run iverson-receive --code XXXX (from the iverson-io package).
  3. Set a Talk key in the Sound Keyboard UI.
  4. Focus a text field, hold the Talk key, speak a 3-digit code, then release.

Privacy

Speech stays on-device. Bluetooth only sends short codes to your nearby computer.
